How to read the board

Columns are A–F left to right, rows 1–6 top to bottom, matching the physical game and the gs_solve command line. Click a cell to toggle a peg, or type the seven cells directly. The nine pieces have areas summing to exactly 29 = 36 − 7, so every solution uses every piece and covers every non-peg cell.

This page ignores the dice that ship with the game, for the same reason the repository does: they exist only to guarantee a solvable board. Any seven pegs are fair game here, including the 2.07% that cannot be solved at all.
